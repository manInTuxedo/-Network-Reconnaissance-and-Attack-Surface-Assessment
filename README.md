# Network-Reconnaissance-and-Attack-Surface-Assessment

## Scenario

Implement a network reconnaissance workflow that discovers authorized targets, identifies exposed services, collects service information, and generates an attack surface assessment report.

## Objective 

Implement a network reconnaissance workflow that discovers authorized targets, identifies exposed services, collects
service information, and generates an attack surface assessment report.

## Learning Focus

• Host discovery and network mapping
• TCP and UDP port scanning
• Service and version detection
• Banner grabbing
• DNS and network information gathering
• Nmap, Netcat, and Python socket programming
• Attack surface documentation

## Phase 1 Deliverables

• Laboratory topology and target inventory
• IP addressing plan and reconnaissance scope
• Scanning strategy and selected tools
• Format for documenting discovered services
• Security considerations associated with scanning
• Configured Kali Linux reconnaissance environment
• Discovery of active hosts in the authorized network
• Port scanning and service enumeration results
• Python script to collect and organize basic service information
• Screenshots and structured reconnaissance report
• Recommendations for reducing unnecessary service exposure

## Expected Results

• Active laboratory hosts and exposed services are documented
• Potentially exposed services are prioritized for further investigation
• Recommendations are provided to reduce the attack surface

## Suggested Environment
Kali Linux + Metasploitable 2
